# Music Decks

音乐理论的选项式记忆卡片，支持中文和英文。本项目在本地开发，通过手动触发 GitHub Actions 发布到 GitHub Pages；不连接或发布到 ChatGPT Sites。

## 运行与测试

- 在项目目录运行 `node server.mjs`，打开 `http://127.0.0.1:4173`
- 运行测试：`node --test tests/core.test.mjs`
- 静态站点文件在 `dist/`，不依赖 OpenAI API、后端服务或第三方运行库

## 练习

- 选择一个或多个卡组后无限随机循环，点击“结束练习”停止
- 所有题目范围由卡组决定，无每轮题数或额外调性筛选
- 左侧为题目，右侧为答案序列；题目和答案均由卡组选项组成
- 虚拟键盘显示完整选项，每个选项点击一次即可填入下一格
- 实体键盘输入匹配选项后自动进入下一格；后续字符若仍属于更长选项，会回接上一格，例如 `C`、`C#`、`C#m`
- `Backspace` 反向逐字编辑；`Enter` 提交，再按一次进入下一题
- 默认和弦名称使用大写音名与小写后缀；普通文字选项忽略大小写
- 音频开关和是否包含题目的选项位于卡片页，可随时切换

## 题库

先创建卡组、定义选项库，再通过选项按钮组合题目和答案。卡组可选择和弦判分或通用文字判分。删除仍被题目引用的选项时会提示先更新对应题目。

默认包含四个卡组：145 与 1645 各分为自然音主音七调（C、G、D、A、E、B、F）和升降音主音五调（F#、Db、Ab、Eb、Bb），共 24 道题。原有两组会自动拆分，保留题目 ID、编辑内容和练习记录。和弦判分区分正确、等音异名与错误。答错的题在两道其他题后优先重现，并提高后续抽中权重；少于三道题时允许提前重复。连续答对延长复习间隔。

## 数据与发布

题库、设置和进度保存在当前浏览器的 `music-decks-v1` 本地存储中。导出 JSON 可完整备份；导入会替换当前数据。与旧 Chord Room 数据分开保存，不覆盖旧记录。不同域名、浏览器和设备不自动同步。

GitHub Pages 托管公开的 `dist/` 文件。网页包含 `noindex, nofollow`，请求搜索引擎不收录，但这不限制访问；公开源码仓库仍可能被搜索到。个人练习记录不会随代码上传。

## 发布新版本

1. 提交并推送本地修改；仅推送不会自动更新网站
2. 首次设置：仓库 Settings → Pages → Source 选择 GitHub Actions
3. Actions → Publish Music Decks → Run workflow，选择 main
4. 工作流先执行测试，再发布 dist/；部署完成后打开输出的网站链接

从 localhost 切换到线上地址时，先在旧地址导出备份，再到线上地址导入，才能带上原来的题库和练习记录。
